# Patternly — Sleep and Habit Tracking Application
A team project developed for Agile Methods course, combining Scrum-based product design with an AI-assisted application development process.

## Project Overview
Patternly helps users record sleep and daily habits, explore patterns in their records, and set and track personal goals.

Our team used a shared Mural board to organize application design through Scrum sprint concepts. My primary responsibility was software development: translating the team's design decisions into a functional application through prompting and iterative AI-assisted coding.

## My Contributions
### Application Development and Integration
- Took primary responsibility for translating the team's application design into a functional prototype using AI-assisted development.
- Directed implementation across the Record, Summary, Plan, and Track screens through detailed prompts and successive revisions.
- Reviewed application behavior and requested changes to connect data entry, pattern summaries, goal creation, and progress tracking into a coherent user journey.

### Product Logic and Data Consistency
- Identified a mismatch between recommendations based on sleep duration and progress charts based on sleep quality. Directed revisions to make sleep duration the primary comparison metric, with sleep quality presented separately.
- Defined a more intuitive date convention in which sleep belongs to the night starting on the selected date, prompting coordinated changes across stored records, summaries, and tracking views.
- Requested current-week and previous-week sleep-quality averages alongside the duration chart to support comparison of both measures.
- Defined requirements for separating each user's profile, daily records, goals, and check-ins.
- Directed AI-assisted implementation of account-based data access so users could manage their own information without accessing other users' records.

### User Experience Refinement
- Simplified the goal lifecycle by removing in-place goal editing and requiring users to end an existing goal before starting a replacement.
- Refined interface hierarchy, labels, explanatory text, and action placement through repeated reviews of the working application.
- Repositioned and restyled the “Give up goal” action to reduce its visual prominence while keeping it accessible.

### Iterative Validation and Demo Preparation
- Exercised the application through local and Codespaces sessions, reporting login failures and working through AI-assisted troubleshooting.
- Coordinated updates to demonstration records and preparation of a classroom version for sharing and presentation.
- Used observations from the running application to guide further revisions beyond the initial generated implementation.

### Development Approach
AI coding tools generated substantial portions of the code. My contribution centered on specifying intended behavior, directing implementation, evaluating the working prototype, and identifying changes needed to align the software with the team's design.

## Application Features
- **Daily records:** Log sleep, mood, water intake, and exercise.
- **Summary:** Visualize records and explore descriptive relationships between habits and sleep.
- **Goal planning:** Create suggested or custom goals with a defined duration.
- **Progress tracking:** Record check-ins and review goal progress.
- **User accounts:** Maintain separate records and settings for individual users.

## Scope
Patternly is an educational prototype demonstrating the connection between collaborative Agile design and software implementation.

The application's pattern summaries use rule-based comparisons of recorded data; they are not generated by an AI service. These observations are exploratory and do not establish causation or provide medical advice.
